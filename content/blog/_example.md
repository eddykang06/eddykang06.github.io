Files whose name starts with `_` are drafts and are not published. Copy this file, rename it (the file name becomes the URL, e.g. `flow-matching.md` → `blog/flow-matching.html`), and change the title and date.

Inline math uses single dollar signs: the loss is $\mathcal{L}(\theta) = \mathbb{E}_{t, x}\left[\lVert v_\theta(x_t, t) - u_t \rVert^2\right]$.

Display math uses double dollar signs:

$$
\frac{d x_t}{d t} = v_\theta(x_t, t), \qquad x_0 \sim \mathcal{N}(0, I).
$$

Regular Markdown works too: **bold**, *italic*, [links](https://example.com), lists, and code blocks.
